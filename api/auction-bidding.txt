Auction Bidding

1. Seller can create an auction for an item at any time.
2. Bidders can place multiple bids on an active auction.
3. A bidder becomes the winner when no higher bid is received
   for 1 hour.
4. Winner gets 10 minutes to complete payment.
5. A bidder can participate in only one active auction at a time.
6. We need to maintain auction and bid state.

Is bidder already participating in another auction?

We can simply query:

SELECT 1
FROM bids b
JOIN auctions a ON a.id = b.auction_id
WHERE b.bidder_id = ?
AND a.status = 'ACTIVE'
LIMIT 1;
