cab booking

1. Rider can request a cab.
2. Request contains pickup and destination.
3. System finds an available cab.
4. Cab gets assigned to the rider.
5. Trip starts and eventually completes.
6. Cab becomes available again after the trip


Rider
  ↓
Request Cab

Assign Cab
  ↓
